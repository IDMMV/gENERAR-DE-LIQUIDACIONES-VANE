# Liquidaciones Vane — Control de Producción

Versión web del generador de liquidaciones y control de producción.

- Procesamiento del Excel en el navegador.
- Conserva la estructura del libro de entrada al generar la liquidación.
- Filtra DETALLE, MAT y RECUPERO por Inspector + Periodo.
- Genera hoja INDICADORES.
- Dashboard con filtros y gráficos de producción.
